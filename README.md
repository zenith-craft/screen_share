## 🌟 About The Project

**SmartBoard Connect** functions as a **Virtual Wireless HDMI Cable**. It pairs your laptop directly with any smartboard or electronic display screen over the internet, allowing you to control screen projection using your laptop's native Windows **`Win + P`** settings or PowerPoint **`F5`** presenter controls — exactly like plugging in a physical HDMI cable!

---

## ✨ Key Features

1. **🔌 Plug-and-Play Wireless HDMI Experience**:
   - Enter the 6-character pairing code on your laptop and the wireless HDMI connection streams live instantly!

2. **⌨️ Native Windows `Win + P` Support**:
   - Control projection modes (Duplicate / Extend / Second Screen Only) natively using your laptop keyboard, exactly as if connected via a physical HDMI cable.

3. **🌐 No Local Wi-Fi Restrictions**:
   - Operates over any internet connection worldwide via WebRTC P2P streaming + WebSocket signaling.

4. **🔑 Dynamic Random Pairing Code**:
   - Every time the Smartboard Receiver page opens, a new random 6-character code is generated.

5. **🌐 Multilingual UI Support**:
   - Instant language switching between **English (EN)**, **Uzbek (UZ)**, and **Russian (RU)**.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v16 or higher)

### Installation & Launch

1. Navigate to the project directory:
   ```bash
   cd C:\Users\HANDSOME\.gemini\antigravity\scratch\smartboard-screen-share
   ```

2. Start the server:
   ```bash
   npm start
   # or
   node server.js
   ```

3. Open in your browser:
   - Local App URL: `http://localhost:3000`
